# PRONINE — демо главной страницы интернет-магазина

Статический сайт без сборки (HTML + CSS + ES-модули). Публикуемая папка — `dist/` (см. `.openai/hosting.json`).

## Запуск
```
node preview.cjs      # http://127.0.0.1:4173
```

## Структура
```
dist/
  index.html                 главная (единственная реализованная страница)
  assets/css/tokens.css      цвета, шрифты, шкала, отступы, параметры анимации
  assets/css/base.css        сброс, контейнер, фокус, появление блоков
  assets/css/components.css  кнопки, шапка, мега-меню, мобильное меню, карточка товара, подсказки
  assets/css/home.css        секции главной
  assets/js/data/products.js модели, фильтры, строки сравнения (единый источник цен)
  assets/js/data/routes.js   карта будущих разделов (все enabled: false, кроме главной)
  assets/js/modules/*.js     header, catalog, picker, soon, reveal
  assets/fonts/              Unbounded и Golos Text (woff2: кириллица, latin, latin-ext — ₽)
  assets/img/                локальные изображения PRONINE
future-pages/                заготовки внутренних страниц (не публикуются)
docs/sources.md              источники фактов и изображений
docs/contradictions.md       противоречия источника и принятые решения
archive/v1-dist/             предыдущая версия демо (для истории)
```

## Правила демо
- Нет внешних переходов и ссылок на padel.pronine.ru; все ссылки — якоря главной.
- Недоступные разделы — `button[aria-disabled="true"]` с подсказкой по наведению/фокусу; клик не меняет адрес.
  На сенсорных экранах подсказка показывается один раз на элемент.
- Нет оплаты, корзины, форм, аналитики и сбора данных. `noindex, nofollow`, без товарной микроразметки.
- Анимации 150–400 мс, отключаются при `prefers-reduced-motion`; без JS весь контент виден (кроме карточек моделей — для них `<noscript>`).

## Как добавить раздел
1. Создать страницу из `future-pages/_template.html` по пути из `routes.js`.
2. Выставить `enabled: true` и заменить соответствующие `aria-disabled`-элементы ссылками.
3. Карточки и цены брать из `products.js` (при появлении бэкенда — заменить модуль на API).
