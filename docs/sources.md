## Слои схемы Control It (анимация раскрытия)
Исходник: `tehnologii-pronine-padel-kak-ustroena-raketka-dlja-padel-tennisa.png` (1024×1236, растр с прозрачным фоном, без отдельных слоёв).
Слои подготовлены скриптом `docs/sketch-layers.py` (Pillow + numpy), линии разреза — `docs/sketch-cut-lines.json`:
- силуэты деталей — размытие альфа-канала, порог, заливка дыр, отбор крупных связных областей;
- разрезы по нижним кромкам дисков Mat Control Finish и Fiberglass (координаты сняты вручную по рисунку);
- `matcontrol.webp`, `fiberglass.webp` — подвижные диски, под карандашом непрозрачная «бумага» по силуэту;
- `base.webp` — неподвижная опора: рама с рукояткой и EVA Soft Core;
- `annotations.webp` — заголовок, подписи, стрелки, выносные и пунктирные линии.
Проверка: сборка слоёв в конечном положении совпадает с исходником (расхождения только в ~260 пикселях полупрозрачной кромки силуэтов).
